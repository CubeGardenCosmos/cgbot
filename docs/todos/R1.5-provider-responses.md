## 执行任务

- [ ] R1.5-T01：确认主 Agent 协议是否统一 Responses，记录与 Codex 原生接口要求的关系；不恢复 §13.6 已作废的 Chat Completions 翻译清单。
- [ ] R1.5-T02：定义单供应商请求、流事件、工具调用/结果与结束/失败的领域接口，使 R1.6 不含供应商请求格式。
- [ ] R1.5-T03：定义模型窗口与实际用量的读取接口，窗口取供应商报告的一个值，交 R2.3 按 50% 触发压缩；token 分母/分子口径待确认，不自行扣除预算（§5.4）。
- [ ] R1.5-T04：定义用途到推理档位的配置映射：压缩摘要 low、私聊 high、任务规划 Max、群聊 low；确认供应商如何表达 Max，群会话总结档位仍待定。
- [ ] R1.5-T05：定义计费/限流信息及错误向调用者的交接，不新增未要求的重试策略；与 M5 对齐 429/故障观测语义，不把 Codex 全局并发降级做进主 Agent 循环。
- [ ] R1.5-T06：形成真实 Responses 联调及元数据来源说明；如 :8788 不支持，记录未满足前提，不靠 gateway 翻译或伪造窗口回退掩盖。

## 测试用例

- R1.5-U01（离线单元）：前置条件：供应商报告窗口 W、用量及用途样例；动作：读取元数据并选择档位；可观察结果：窗口不被重复分段，四类已定用途映射准确，Max 不静默降档。
- R1.5-U02（离线单元）：前置条件：带工具调用、结束和失败的流样例；动作：经供应商接口转换；可观察结果：R1.6 获得完整调用/参数与明确完成或失败，不把截断流当成功。
- R1.5-I01（真实边界集成）：前置条件：获授权且确认支持 Responses 的真实上游；动作：执行流式请求、工具往返及档位请求；可观察结果：协议、模型窗口来源、档位与实际响应留证，无 Chat 协议翻译。
- R1.5-C01（检查/平台）：前置条件：供应商接口与配置说明；动作：核对请求格式、窗口、档位、计费/限流及密钥归属；可观察结果：供应商专有内容不散落 Agent 层，真实 token 不进文档日志。
