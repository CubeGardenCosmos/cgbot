## 测试用例

- R5.1-U01(离线单元):前置条件:本地受控上游与内部/真实令牌样本;动作:使用合法和非法内部令牌请求;可观察结果:合法请求到上游时注入真实凭据,非法请求不抵达上游,沙盒响应不泄露真实密钥。
- R5.1-U02(离线单元):前置条件:SSE 分片与 zstd 请求样本及已确认透传契约;动作:经过 gateway 传输;可观察结果:事件与请求体不被翻译/缓冲合并,Content-Encoding/Content-Length 不因错误改写破坏请求。
- R5.1-I01(真实边界集成):前置条件:用户授权、原生 Responses 上游确认、Codex 沙盒可用;动作:经 gateway 完成流式响应、多轮工具及 apply_patch 调用;可观察结果:Codex 正常收到完成事件,全程无 chat 翻译,真实密钥不进入沙盒。
- R5.1-C01(检查/平台):前置条件:gateway 与配置交付;动作:检查请求路径、密钥来源及实现边界;可观察结果:无 DSH 专用请求依赖、无协议翻译层,单供应商约束一致。

## 完成证据

离线(tests/coding_gateway,83 通过,ruff/pyright 通过):
- U01:伪造/错型/他人 secret 令牌 401 且不抵达上游;合法请求以 `Authorization: Bearer <上游密钥>` 注入,沙盒令牌与 secret 不转发。
- U02:SSE 增量透传、zstd 原始字节一致、hop-by-hop 头剥离、上游 429/500/503 原样保留(含 Retry-After)、上游不可达返回 502。
未执行:R5.1-I01(真实上游,需用户授权)、R5.1-C01、R0.1 上游 Responses 外部验证(T01)、T04(Codex 配置不属于本切片)、T03 真实路径确认。
推论:令牌 `cgb-`/`cgw-` 前缀为本切片选择;流中断/客户端断开时关闭连接而非补终止块;入站 `auto_decompress=False`;`handler_cancellation=True` 使断开时取消上游请求(影响 R5.x 桥接设计)。
