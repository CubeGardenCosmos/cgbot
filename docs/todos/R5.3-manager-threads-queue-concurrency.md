## 待决策(推论,待与 A/C/H 切片确认)

- §13.6b 故障分类(推论):连接失败(0)、429、5xx 计入;其它 4xx 不计。降级不杀已运行 turn,只阻止新启动。
- §13.6b 恢复计时(推论):恢复时刻 = max(降级时刻, 最后一次 429) + 1 小时。
- §13.7 断线/重启(推论):运行中 turn 经 `thread_resume` + `thread_status` 对账;状态非 active 或超时则记 `turn_failed` 一次,最终文本不恢复。断线期间已完成的 turn 也记为失败。
- §13.7 启动失败(推论):任何 `turn_start` 异常都丢弃 session 并重连;同一指令 3 次失败后丢弃并通知。语义性错误同样会触发重连。
- `thread_fork` 返回 `state="started"`、`queue_position=0`,但不启动 turn(契约含糊)。
- `thread_resume` 同时作为归属校验:外部 thread id 在本用户沙盒中失败即返回 "thread not found"。
