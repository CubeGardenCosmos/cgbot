- 推论(待用户确认):默认值最近 3 个带图轮次、长边 1536、每范围保留 200 张/30 天、单条 4 张。
- 未决:引用(回复)消息的图片——当前没有取回被引用消息的能力,未新增 NapCat 取消息动作。

- 已知:启用沙盒时,私聊同一张图片会被下载两次(收件箱与聊天各一次),未合并。
- 已知:压缩阈值估算不含图片 token,依赖上游返回的 usage 校正。
