## 测试用例

- R5.7-U01(离线单元):前置条件:连接存储约定与两个用户样本;动作:分别执行 add/list/del;可观察结果:流程接受既定四类私聊录入字段,用户连接不串用,不生成 Codex manager 连接。
- R5.7-U02(离线单元):前置条件:受控 omp 后端忙碌、模糊目录及账户额度响应;动作:发送新指令、解析目录、读取额度;可观察结果:使用 omp 队列与原能力,不路由 codex_* 或删去保留能力。
- R5.7-U03(离线单元):前置条件:监视隔离/超时契约已确认,模拟慢连接;动作:监视期间处理框架私聊事件;可观察结果:主循环仍可处理消息,失败归属原连接而非阻塞全局。
- R5.7-I01(真实边界集成):前置条件:用户授权的实际 ompweb 与好友白名单;动作:私聊关联后创建任务、忙时续发、读取状态/历史/账户额度并接收报告;可观察结果:实际任务与队列正确,回报回到关联用户,保留目录解析能力。
- R5.7-C01(检查/平台):前置条件:工具交付;动作:检查注册、依赖、凭据存储与后台监视;可观察结果:保留独立 omp_* 名称,无 AstraBot 钩子依赖、无统一后端工具层,存储方式符合确认约定。
