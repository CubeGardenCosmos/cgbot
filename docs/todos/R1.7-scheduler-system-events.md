## 测试用例

- R1.7-U01（离线单元）：前置条件：可控时间与按确认空闲口径登记的任务；动作：推进到 8 小时，不发送新用户消息；可观察结果：产生一次到期压缩触发，摘要执行由 R2.3 承接。
- R1.7-U02（离线单元）：前置条件：两用户的系统事件及一个正在运行轮次；动作：交错入队与消费；可观察结果：归属不串，忙时顺序按确认规则执行，无旁路并行请求。
- R1.7-I01（真实边界集成）：前置条件：未来真实队列/存储实现与独立测试进程；动作：入队、进程终止、重启消费并触发 Agent；可观察结果：恢复与重复交付符合已确认语义，工具外发不因未经定义的重放而重复。
- R1.7-I02（真实边界集成）：前置条件：获授权的真实模型边界与后台完成事件；动作：入队唤醒轮次；可观察结果：事件进入正确私聊上下文，由 reply 工具发送，不依赖 AstraBot 或下一条来信。
- R1.7-C01（检查/平台）：前置条件：调度/事件契约；动作：检查 M2/M3/M5 调用边界与白名单；可观察结果：无范围外唤醒，群门控不被绕过，Codex thread FIFO 未被混同为系统事件队列。
