## 待决策

- §5.2、§5.4:摘要加尾部、原记录保留、尾部长度/选取、摘要提示词配置、用量是否含系统提示/工具定义/输出预留,工具输出截断/落盘。
- §5.3:8 小时压缩是否同时沉淀记忆,未定,不能默认为写入触发。
- §5.4:主动压缩恰逢新消息的并发;空闲的活动口径、压缩后是否再次排 8 小时、恢复后的到期处理未指定。
- 压缩失败时的会话可用性与后续动作未指定,需先收束而非暗加重试策略。
- 推论(已在代码中采用,待确认):尾部保留最近 3 个交换,切点前移以避开拆开的工具调用对与未应答调用;摘要提示词为代码内默认值,未做配置;用量阈值 `2*tokens >= window`,不计输出预留;空闲活动口径为会话最后一行时间(含压缩行),仅私聊,压缩完成后不再次排期,下一条活动重新排期;失败不重试,仅报告异常类名;压缩提交使用 `append_if_last` 比对,期间有新行则放弃并标记 superseded。
