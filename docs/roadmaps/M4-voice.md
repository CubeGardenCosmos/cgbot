## 待决策

- §11.3:同机读取还是共享挂载解决 SoVITS 返回路径可读性;部署位置依 §12.1 暂不讨论,不得据此直接选址。
- §11.3:QQ 语音解码/WAV→silk 工具与依赖选型;NapCat 能否直接接收 WAV 仍待验证,不据此省略转换规划。
- §11.3:将旧 smart/开关/关键词逻辑改为模型选择回复发送形式只是推论;工具参数、触发规则待定。
- §12.2:客户端并发与超时设置仍是推论,需结合两进程共享 GPU、各服务串行处理和长句合成耗时确定;不能默认沿用 30 秒。
- §11.3、§11.9:客户端连接生命周期、错误与不可读路径处理、媒体临时文件清理策略待定;服务端文件永不清理的现状不等于允许客户端删除服务端文件。

## 与其他阶段的接口

- M1 提供配置、范围白名单、Record 消息段与回复出口;R4.3 不另建身份或渠道路由。
- 私聊输入状态与运行中新消息仍遵循 M2,语音不绕过 Agent 循环;语音转写何时计入输入等待需随触发规则细化。
- 群语音服从 M3 门控与隐私边界,不以转写为由绕过静音期间不记录、不缓冲、不传 LLM 的约束。
- 微信入口后置至 M6;本阶段不接微信媒体协议。真实边界用例待授权与可达环境具备后执行,本轮仅文档。
