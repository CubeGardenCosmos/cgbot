## 测试用例

- R1.6-U01（离线单元）：前置条件：模型只输出普通文本；动作：完成一轮；可观察结果：入口发送次数为零，内部处理按确认策略记录。
- R1.6-U02（离线单元）：前置条件：带来源/消息 ID 的上下文；动作：调用 reply，分别省略目标及指定引用；可观察结果：默认回来源，引用精确交给发送接口，不接受不存在/越归属目标。
- R1.6-U03（离线单元）：前置条件：工具调用成功、失败和无 reply 三类轮次；动作：继续或结束模型循环；可观察结果：结果关联正确，沉默与错误可区分，没有模型文本自动兜底外发。
- R1.6-I01（真实边界集成）：前置条件：获授权的真实上游与好友 QQ；动作：模型调用 reply 引用来信；可观察结果：真实 QQ 收到工具发送内容与正确引用，模型普通文本不额外发送。
- R1.6-C01（检查/平台）：前置条件：循环与工具契约；动作：核对输入中/steering 接口和工具边界；可观察结果：R2.1 可阻止输入中请求，R2.2 可识别是否调用工具；未引入 DSH 或后端无关任务工具层。
