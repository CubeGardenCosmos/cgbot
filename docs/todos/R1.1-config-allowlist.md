## 完成证据

- 实现：`src/cgbot/config/settings.py`（冻结数据类）、`loader.py`（`load_config`）、`__init__.py`（格式说明与导出）、`config.example.toml`（仓库根）。
- 命令与结果：
  - `uv run ruff format src/cgbot/config tests/config`：格式化 1 个文件后，复跑 5 个文件无变化。
  - `uv run ruff check src/cgbot/config tests/config`：All checks passed。
  - `uv run pyright src/cgbot/config tests/config`：0 errors, 0 warnings。
  - `uv run pytest tests/config -q`：66 passed（仅有仓库既有 pytest-asyncio 配置告警，非本模块）。
- 推论（DESIGN.md 未决定，已在实现中采用）：
  - 配置格式：TOML；密钥文件为 `[secrets]` 表（扁平 `name = "value"`），主配置仅以 `*_ref` 引用密钥名。
  - 密钥来源优先级：环境变量 `CGBOT_SECRET_<NAME>` 覆盖 secrets 文件；secrets 文件路径为 `load_config` 参数，否则 `CGBOT_SECRETS_FILE`，否则不读文件。显式指定的文件缺失即报错。
  - secrets 文件权限须为 0600（组/其他无任何权限），与 R0.2 密钥约定对齐。
  - 必填：`napcat.port`、`provider.base_url`（http/https）、`provider.model`、`provider.api_key_ref`。缺省：`napcat.host=127.0.0.1`、`napcat.path=/ws`、`group.wake_keywords=["大肥鱼"]`、`group.mute_keywords=[]`、`storage.data_dir=data`（相对配置文件目录）、`logging.level=INFO`、推理档位取值为 summary low / private high / planning max / group low。
  - 缺省范围为全部拒绝：未配置 `[scope]` 或名单为空即无任何放行。
  - QQ 号以纯数字（TOML 整数或数字字符串）读入并规范为字符串。
  - `scope.owner` 仅为身份标记，不自动加入白名单；群内成员不以好友身份为前提（群聊范围仅看群号）。
  - 未知键在每一层表均报错，并给出点分键路径；所有错误信息不回显密钥值。
  - 加载一次，不支持热重载；`Config` 及子对象均为冻结数据类。
- 公开 API：`load_config(path, secrets_path=None, env=os.environ) -> Config`；`ScopeConfig.allows(scope: Scope, user_id: str, group_id: str | None) -> bool`；`ConfigError(key, message)` 带 `.key`/`.message`；`Secret.reveal()`。
- 未改动共享类型 `src/cgbot/model.py`。
